# GamesWhats

Bot de WhatsApp dedicado exclusivamente a juegos HTML interactivos que se ejecutan dentro del mensaje de WhatsApp.

El proyecto está inspirado en el transporte de juegos utilizado por Ghost Nexora Bot, pero se mantiene aislado: no incluye economía, IA, descargas, RPG, moderación, tienda ni otras funciones. Su única finalidad es servir mini juegos autocontenidos como Mario, Dino y Ninja mediante rich responses de WhatsApp.

## Juegos

- `.mario` — mini plataformas.
- `.dino` — runner estilo dinosaurio.
- `.ninja` — Fruit Slice táctil.
- `.snake` — Snake.
- `.spacedodge` — esquivar asteroides.
- `.doom` — mini arena/shooter.
- `.gato` — tres en raya contra IA.
- `.damas` — damas táctiles contra IA.
- `.games` / `.juegos` — catálogo.
